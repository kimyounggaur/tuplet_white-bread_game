# UX4 구현 결과와 검증 범위

2026-11-20 · 구현 완료, 실제 사용성 검증 대기

## 구현

처음 방문한 사람은 메뉴나 청음 확인에 앞서 한 박짜리 식빵을 두 번 눌러 세 조각으로 만든다. 두 줄의 시작과 끝은 같고 두 조각과 세 조각을 각각 한 박 동안 비교한다. 되돌리기·소리 끄기·건너뛰기와 정규 주문 진입을 지원한다.

유효한 이어하기나 이전 진도, 맛보기 완료 기록이 있으면 기존 제목 화면을 연다. 특정 주문·발견 장면·자가검사 해시는 그대로 직행한다. 맛보기 중에는 정규 진행 기록을 쓰지 않고, 정규 진입 시 settings.introSeen과 튜토리얼 1단계를 기록한 뒤 기존 첫날 진입 함수를 부른다.

작업은 로컬 ux/first-play-intro 브랜치에서 수행했다. 루트 HTML은 tools/build.mjs에서 생성했다. 원격 GitHub 및 Vercel 변경을 수행하지 않았다.

## 화면 근거

대화의 ‘320픽셀 맛보기 화면 확인’, ‘키보드로 세 조각과 비교 전환 확인’, ‘360픽셀 맛보기와 비교 화면 기록’, ‘재생 종료와 두 줄 비교 화면 확인’ 캡처를 남겼다. 브라우저 iframe 크기 에뮬레이션이며 실제 휴대전화 사진이 아니다. 비교 화면은 작은 높이에서 내부 세로 스크롤을 허용한다. 첫 두 입력의 빵 버튼 노드를 유지하고 비교 제목으로 포커스를 옮긴다.

두 비교 버튼을 실제 브라우저에서 눌러 ‘선택한 줄이 한 박 동안 재생돼요’와 종료 표기를 확인했다. 이것은 실제 휴대전화 청음과 무선 이어폰 지연의 근거가 아니다.
