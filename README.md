# 잇단음표 식빵 공방

음악이론 학습용 모바일 웹 게임입니다. 식빵의 길이로 음표 길이를 읽고 같은 크기로 나누면서 일반 분할과 잇단음표를 구별합니다.

## 실행

브라우저에서 `index.html`을 엽니다. 연결이나 설치가 필요하지 않습니다. 첫 손짓에서 소리가 허용됩니다. 기록은 브라우저와 기기 안에 남습니다.

- `index.html#test`에서 자가검사 51개를 확인할 수 있습니다.
- `#d3-02`로 특정 주문, `#S2`로 발견 장면을 바로 열 수 있습니다. 이 경로에서 한 영업은 기록에 반영되지 않습니다.

## 개발

`src/`에서 수정한 다음 Node.js로 `node tools/build.mjs`를 실행합니다. 런타임은 루트의 `index.html` 한 파일입니다.

`tools/check.mjs`와 `tools/progress.mjs`는 Playwright와 Chromium을 사용할 수 있는 환경에서 실행하는 브라우저 점검입니다. 브라우저 바이너리는 `CHROME` 환경변수로 지정할 수 있습니다.

구현 단계와 검증 범위는 [게이트 보고서](docs/slice-gate-report.md)에 있습니다.
